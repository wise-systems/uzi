### Added

- **A repo created after this release can be linked to a YouTrack project and eligibility tag, and tagged issues start runs (#4173).**
  The link is made before the repo's first enable; tagged issues sync onto the board with their YouTrack key (`ABC-12`), and comments and issue text by accounts other than the connection's own are withheld or need approval; issue writes on a linked repo come in a later release. Roll out the API before the workers: a worker needs `issue_key_v1` to claim a linked run.
